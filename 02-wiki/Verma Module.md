# Verma Module
**Prerequisites:** [[Universal Enveloping Algebra]], [[Category O (Hub)]]

## Definitions
A Verma module is a universal highest weight module over a universal enveloping algebra. It serves as a building block for finite-dimensional representations and simple modules in Category O.
