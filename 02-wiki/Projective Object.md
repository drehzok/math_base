# Projective Object

An object $P$ in a category $\mathcal{C}$ is **projective** if for every epimorphism $f: A \to B$ and every morphism $g: P \to B$, there exists a morphism $h: P \to A$ such that $f \circ h = g$.

In module categories, an object is projective if and only if it is a direct summand of a free module.
