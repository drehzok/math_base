# Projective Cover
**Prerequisites:** [[Projective Object (Hub)]]

## Definitions
A morphism $\phi: P \to X$ is a **projective cover** if $P$ is a projective object and $\phi$ is an essential epimorphism. This means that if $\psi: Q \to P$ is a morphism such that $\phi \circ \psi$ is an epimorphism, then $\psi$ must be an epimorphism.

## Theorems
- If projective covers exist, they are unique up to isomorphism.
- The map from a projective cover to a simple object is unique up to isomorphism.
