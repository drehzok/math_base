# Indecomposable Object
**Prerequisites:** [[Additive Category]]

## Definitions
An object $X$ in an additive category is indecomposable if it is not isomorphic to the zero object and cannot be written as a direct sum of two non-zero objects.

## Properties
For an object $X$ satisfying the bichain condition, $X$ is indecomposable if and only if its endomorphism ring $\operatorname{End}(X)$ is local.
