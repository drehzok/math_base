# Projective Object
**Prerequisites:** [[Category Theory]]

## Definitions
An object $P$ in an abelian category is **projective** if, for every epimorphism $M \to N$ and every morphism $P \to N$, there exists a lift $P \to M$ making the diagram commute.

## Properties
Any object can often be covered by a projective object. In Category O, understanding projectives is key to decomposing modules.
