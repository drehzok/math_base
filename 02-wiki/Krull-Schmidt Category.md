# Krull-Schmidt Category
**Prerequisites:** [[Additive Category]], [[Indecomposable Object]]

## Definitions
An additive category $\mathcal{C}$ is a Krull-Schmidt category if every object $X \in \mathcal{C}$ can be written as a finite direct sum of indecomposable objects with local endomorphism rings.
That is, $X \cong \bigoplus_{i=1}^n X_i$ with $X_i$ indecomposable and $\operatorname{End}_\mathcal{C}(X_i)$ local.

## Properties
A ring $R$ is semiperfect if and only if finitely generated projective objects form a Krull-Schmidt category.
